What this is mocking

In production this panel would be a real Slack channel: someone posts a spend request in plain English, and an ops bot files it through the same pipeline as the web form.

  • Show the exact change — the bot parses the message and posts back exactly what it would file (vendor, amount, bucket, routing).
  • Wait for confirmation — nothing is submitted until a human confirms in the app.
  • File it — same validation, same tier rules, same splitting check.
  • Read it back — the ledger write is verified, and the receipt is reported in-channel.
  • Flag, don't guess — missing fields go to a human instead of being invented.

Requests filed this way carry a "via Slack" badge in the queue and ledger.
